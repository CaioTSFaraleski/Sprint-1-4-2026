## Definição de Pronto (Definition of Done)

Um item da Sprint 3 é considerado **pronto** quando:

1. O artefato (tela, documento ou código) está publicado no local combinado (Figma, repositório GitHub ou Trello).
2. Há correspondência explícita com pelo menos um requisito funcional/não funcional ou caso de uso da Sprint 1.
3. O README do repositório foi atualizado com o link e uma breve descrição do artefato.
4. O item foi revisado por, no mínimo, um integrante além do responsável original (registrado como comentário no card do Trello ou como aprovação na Review).
5. Não há pendências abertas relacionadas ao item na coluna "Em revisão" do board.
